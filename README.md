# JavaFX Calculator

A graphical calculator built with **Java** and **JavaFX**, featuring arithmetic and other mathematical operations.

<img width="122" height="268" alt="JavaFX_Calculator" src="https://github.com/user-attachments/assets/1c68eaac-0576-43b6-91b0-fbcf4db91382" />

## Features
* Addition, subtraction, multiplication, and division
* Percentage calculations
* Square and square root
* Reciprocal (`1/x`)
* Positive/negative toggle
* Backspace and clear functions
* Calculation history display
* Graphical user interface built with JavaFX

## Technologies
* Java 23
* JavaFX 21
* Maven

## Getting Started

### Prerequisites
* JDK 23 (or compatible version)
* No need to install Maven separately — this project uses the Maven Wrapper

### Running the App
1. Clone the repository:
```bash
   git clone https://github.com/devmenahil/JavaFXCalculator.git
   cd JavaFXCalculator
```
2. Run using the Maven Wrapper:
```bash
   ./mvnw javafx:run
```
   On Windows:
```bash
   mvnw.cmd javafx:run
```
